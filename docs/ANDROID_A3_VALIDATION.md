# Android A3 可选服务器 MVP（2026-10-04）

状态：已实现最小客户端链路，真机 NAS 验收待完成；不代表完整 M2 退出条件通过。

## 范围

- 本地曲库保留独立入口，服务器设置默认关闭。用户主动开启、保存 http/https 根地址并同步后才访问服务器。没有后台自动发现、自动同步或管理扫描请求。
- 调用现有 v1 server/catalog/song/chart/asset API；展示服务名称、版本、曲数及四轨难度。完整清单以 AtomicFile 保存，服务器地址独立标识来源，revision 独立隔离详情、谱面和音频缓存。同名本地/远程歌曲不会合并。
- 选曲前准备谱面与音频，校验谱面有效、下载字节数与清单一致；不完整下载不成为可游玩资源，可再次准备重试。网络和文件操作在后台准备线程；GameActivity 只接收应用私有文件，游玩时没有服务器客户端依赖。
- 已同步清单离线可见，已准备的歌曲可从缓存再次准备；未下载资源需要服务在线。404、超时、地址错误、下载大小不一致会显示错误。完整同步替换快照，旧 revision 不复用；服务关闭不影响本地游玩。
- 单个来源音频缓存最多 512 MiB，可确认清除服务器缓存，保留本地曲包。旧 revision 资源在手动清除前保留，尚无自动淘汰。由于 API 没有资源内容哈希，当前按 revision/资源 ID/大小失效，不能证明同大小内容的完整性。

## 验收范围与限制

使用仓库真实 Python FoxDroid 内容服务，仅监听 Primary 的 127.0.0.1:18080，通过 adb 通道连接 API 35 模拟器，曲库仅包含原创八秒 WAV/SM。不访问用户 NAS，不上传用户曲包。
