# Android A2 游玩原型验证（2026-10-04）

状态：部分完成，等待真机音频和多指验收；不是完整 A2 出口验收。

## 实现

- 本地谱面准备后进入原生横屏四轨 Canvas 页面，不使用 WebView、网络或服务器。
- MediaCodec 在准备阶段预解码为内存 PCM；AAudio 原生回调只复制 PCM。通过硬件播放时间戳建立音频时钟，MotionEvent 单调时间戳用于输入，显示帧仅负责绘制。硬件时间戳不可用时暂停，不用绘制时钟替代。
- 四指状态管理、Tap/Hold/Roll/Mine 判定、离线结算、上次成绩保存；音频、输入和视觉偏移分别保存。
- 顶部点击或系统返回暂停，释放音频流；继续时从保存位置重建。后台和音频焦点丢失也请求暂停。
- 直接使用 Android AAudio API（Android 10 最低版本），当前没有引入 Oboe。请求 LOW_LATENCY，并显示实际输出模式、缓冲和 underrun。

## 已验证

- debug APK 构建成功，原生库包含 arm64-v8a 和 x86_64；lint 0 错误、29 警告。
- JVM 10 个测试方法通过，包含 5 组共享谱面向量、5 组共享判定向量、四指/重叠轨道/移轨/取消状态测试及本地来源测试。
- API 35 模拟器安装最终包，选曲、独立谱面准备、原生播放时钟及无输入完整结算通过；结果 Miss=8、持续音符 Missed=2、地雷 AvoidMine=1。无 AndroidRuntime 崩溃日志。
- 原型前一轮模拟器验证单点输入、手动暂停/继续和重启后上次成绩保留。运行截图见 android-evidence/a2-running.png。
- 原创 8 秒 WAV 测试素材被复制到模拟器应用私有曲库，音频实验没有重新验证导入选择器；A1 导入验收记录独立保留。
- 模拟器实际输出 48000 Hz、burst 960、buffer 4360、underrun 0、performance mode 10（NONE）。这不能证明真机低延迟。模拟器使用 no-audio，宿主可听声音未验收。
- 用户此前报告 A1 重启与重复导入通过；A0 返回、旋转、后台、锁屏恢复正常，60 Hz 识别正确。这些结果不替代新游玩页验收。

## 限制与待验证

当前使用 Canvas；判定和计分在结算时批量评估，尚无实时判定反馈和完整成绩历史。Mine/持续音符结果单独展示，正式计分规则仍待完善。预解码限制 24 MiB PCM、最多 2000 音符、前导不超过 2 秒，仅处理单/双声道。MP3/OGG 未在本轮验证。

Activity 重建和进程死亡没有完整局内恢复。模拟器锁屏恢复实验未获得可靠证据，不能报告通过。真实声音、四指同时输入、Hold/Roll、暂停续播、锁屏/后台中断、实际 underrun 和延迟校准待真机检查。系统旋转建议按钮偏好仍待处理。NAS 仍默认关闭，A3 未开始。
